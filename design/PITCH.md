# Pitch 적용 기준

공통 기준은 `DESIGN.md`, 토큰은 `tokens.css`를 따른다. 이 문서는 Pitch(구 튜너)에만 해당하는 내용이다.

## 앱 이름

- 표시 이름: "튜너" → `Pitch`
- 상단 바 워드마크: `PITCH`
- manifest `name`, `short_name`, HTML `<title>`도 Pitch로 변경

## 화면별 변경

### 튜너 (메인)

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 왼쪽 | 원형 악기(줄) 아이콘 버튼 | 상단 바 왼쪽은 `PITCH` 워드마크. 이 버튼의 기존 기능은 유지하고 오른쪽 텍스트 버튼으로 이동(예: 현재 악기명 "기타" 또는 "베이스") |
| 자동 감지 | 흰 알약 + 초록 점 "자동 감지" | 제목 위 보조 라벨: Ember 점 + "자동 감지" (감지 중일 때만 점 표시) |
| 정지 | 흰 알약 + 검정 사각 "정지" | 상단 바 텍스트 버튼 "정지" (정지 상태에서는 "시작") |
| 설정 | 원형 톱니 버튼 | 상단 바 텍스트 버튼 "설정" |
| 음 표시 | 큰 흰 원 안의 회색 E, 아래첨자 2 | 원 없음. 150px 900 글자, 음 이름은 연회색(#D6D6D6), 옥타브 숫자는 검정 48px |
| 안내 | "줄을 튕기십시오" | 22px 800 글자, 왼쪽 정렬 |
| 음정 막대 | 둥근 회색 트랙 + 원형 손잡이, 낮음/정확/높음 | 아래 검정 1px 기준선 + 5% 간격 눈금(중앙 눈금은 검정, 길게), 현재 음정은 Ember 세로 막대(너비 9px), 아래 라벨 낮음 / 정확 / 높음 |
| 줄 선택 | 기타 헤드 그림 + 원형 줄 버튼 6개 | 섹션 라벨 "줄 선택" + 밑줄 탭: 자동 / E2 / A2 / D3 / G3 / B3 / E4 (베이스는 자동 / E1 / A1 / D2 / G2). 줄을 고르면 그 줄로 고정되는 기존 동작 유지 |
| 하단 안내 | "줄을 탭하면 그 줄로 고정됩니다" | 줄 선택 탭 아래 Gray 12px |

### 음이 맞았을 때 (정확 상태)

- 음 이름 글자색을 연회색에서 검정으로 바꾼다.
- "정확" 라벨을 굵게(800) 표시한다.
- 초록색은 쓰지 않는다. 기존에 초록으로 표시하던 모든 상태를 이 방식으로 바꾼다.

### 설정 (시트)

| 영역 | 현재 | 변경 |
|---|---|---|
| 시트 모양 | 둥근 상단 바텀시트, 손잡이 막대 | 상단 직선 + 검정 2px 선, 손잡이 막대 없음, 뒤 배경 `--pf-dim` |
| 제목 | "설정" | 30px 900, 오른쪽 텍스트 버튼 "닫기" |
| 악기 선택 | 큰 카드 2개(선택은 검정 채움) | 섹션 라벨 "악기 선택" + 목록 2행: "기타 / 6현 · E A D G B E", "베이스 / 4현 · E A D G". 오른쪽 10px 사각 표시(선택은 검정 채움, 미선택은 테두리만) |
| 기준음 | 소리굽쇠 아이콘 + 설명 + 원형 −/+ 버튼, 440Hz | 섹션 라벨 "기준음 (A4)" + 한 줄: 텍스트 버튼 "−", 가운데 34px 900 "440Hz", 텍스트 버튼 "+". 설명은 아래 Gray 13px |
| 완료 | 둥근 검정 버튼 | 주 버튼(전체 폭 검정 바), 시트 맨 아래 |

## Ember 사용 위치 (Pitch)

- 현재 음정 막대
- 자동 감지 중 표시 점

## 하지 말 것

- 음 감지 로직, 주파수 계산, 마이크 처리, 기준음 계산은 건드리지 않는다.
- 기타 헤드 그림을 다른 장식 그림으로 대체하지 않는다(줄 선택은 탭으로만).
